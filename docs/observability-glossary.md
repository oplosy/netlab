# Observability Glossary

Terms used when wiring up monitoring for the lab.

- **Sweep** — one automated pass over the managed inventory.
- **Probe** — a single check against a target, part of a sweep.
- **Run** — one execution of the automation against the lab.
- **Evidence** — collected proof that a run behaved as expected (logs, dumps, counters).
- **Blue box** — lab-internal placeholder for a device or service under test.

Metric names and labels should read as this glossary; if a new dashboard needs a new word, add it here.
